H3 REFERENCE DIRECTOR - WORKFLOW 01 v2.0 - MODEL DOWNLOAD COMMANDS FOR RUNPOD
=============================================================================

The installer downloads only one model file: the 10 MB live-preview decoder
(taeh3). Everything else is listed here: the same files and links as
H3_Reference_Director_01_v2.0_MODELS.pdf, written as commands you paste into
the RunPod terminal yourself. Paste only the ones you need.

  - Paste STEP 0 first, in every new terminal. It sets the models folder that
    the other commands use.
  - Each command resumes an interrupted download (wget -c). If one stops,
    paste it again. Never rename a half-finished file.
  - When you are done, run the installer again. Its model check compares
    every file with the size Hugging Face lists and reports complete,
    missing or damaged.
  - If a download answers "401 Unauthorized", that repository wants you to be
    logged in: accept its terms on huggingface.co, create a read token, and
    add  --header="Authorization: Bearer hf_YOUR_TOKEN"  after "wget -c".


STEP 0 - paste this first
-------------------------
M=/workspace/runpod-slim/ComfyUI/models
[ -d /workspace/runpod-slim/ComfyUI ] || M=/workspace/ComfyUI/models
mkdir -p "$M/diffusion_models" "$M/text_encoders" "$M/vae" "$M/loras" "$M/latent_upscale_models" "$M/ultralytics/bbox" "$M/vae_approx"
